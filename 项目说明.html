3三个关键实现

① Vision 坐标 → 视图坐标（最容易写错的地方）

Vision 的 boundingBox 是归一化坐标且原点在左下角，UIKit 原点在左上角，必须翻转 Y 轴。 贴纸尺寸在原始人脸框基础上外扩 16%，确保盖住发际线与耳侧；旋转角取 -roll。

EditorViewController.swift
private func canvasRect(for normalizedRect: CGRect, in canvasSize: CGSize) -> CGRect {
    let width  = normalizedRect.width  * canvasSize.width
    let height = normalizedRect.height * canvasSize.height
    let x = normalizedRect.minX * canvasSize.width
    let y = (1 - normalizedRect.maxY) * canvasSize.height   // Y 轴翻转
    return CGRect(x: x, y: y, width: width, height: height)
}

② 手势交互：缩放不用 transform，改用 bounds + 字号

这样 emoji 放大 5 倍依然锐利，并且导出渲染可以直接复用 baseSize × scale 的几何数据。捏合与旋转通过 shouldRecognizeSimultaneouslyWith 同时生效。

EditableItemView.swift
private func apply(center:relative, scale:CGFloat, rotation:CGFloat, opacity:CGFloat) {
    self.center = center
    bounds = CGRect(x: 0, y: 0,
                    width:  baseSize.width  * scaleFactor,
                    height: baseSize.height * scaleFactor)
    transform = CGAffineTransform(rotationAngle: rotationAngle)  // 只负责旋转
    contentView?.alpha = opacityValue
    applyContentAppearance()   // 同步字号，保证清晰
}

③ 导出合成：与原图分辨率一致，且所见即所得

画布坐标（point）与导出坐标（像素）相差一个系数 scale； 预览视图与导出渲染使用完全相同的中心点 / 缩放 / 旋转 / 透明度， 因此导出结果与编辑界面像素级一致。最长边超过 4096px 才等比收敛，防止内存溢出。

EditorRenderer.swift
let scale = basePixels.width / canvasSize.width
cgContext.translateBy(x: item.center.x * scale, y: item.center.y * scale)
cgContext.rotate(by: item.rotation)
cgContext.setAlpha(item.opacity)
// 在该变换下绘制 emoji / 图片 / 文字

6如何运行

把整个 FaceShy 文件夹拷到 Mac，双击 FaceShy.xcodeproj 打开工程。
Scheme 选 FaceShy，挑一台 iPhone 模拟器（如 iPhone 15），按 ⌘R 运行。
真机运行：Target → Signing & Capabilities 勾选 Automatically manage signing 并选择你的 Apple ID Team。
把 com.faceshy.app 改成独一无二的 Bundle Identifier，否则无法签名安装。
模拟器没有相机，请用「从相册选择照片」；先把图片拖进模拟器窗口即可存入相册。
新增 / 删除 .swift 文件后，执行 python3 tools/generate_xcodeproj.py 刷新工程文件。
AppIcon 目前是空壳，可正常编译运行，仅缺图标；上架前放一张 1024×1024 PNG 到 Assets.xcassets/AppIcon.appiconset/ 即可。

7如何拿到 IPA 并自签安装

⚠️ 硬约束：iOS 应用无法在 Windows / Linux 上编译。
UIKit、Vision、iOS SDK 只存在于 Apple 的 Xcode 工具链里，没有 Windows 替代方案。产出 IPA 必须经过 macOS。 下面两条路线都已在本仓库中配置好。

路线 A · GitHub Actions 云端 macOS 构建（推荐，不需要自己有 Mac）

工作流文件已就位：.github/workflows/build-ipa.yml，使用免费的 macOS 运行器。 本地仓库已完成首次提交（43 个文件），你只需推上去。

① 建空仓库：github.com/new， 仓库名如 face_shy，Public / Private 都行； ⚠️ 别勾 Add a README / .gitignore / License（会有冲突）。

② 推送（一条命令，脚本会自动补提交 + 配 remote + 失败给排查指引）：

Git Bash / 终端
cd FaceShy
./push_to_github.sh 你的GitHub用户名

③ 等构建：推送即触发，去 github.com/你的用户名/face_shy/actions 看进度（2~4 分钟）。 也可手动 Actions → Run workflow，顺便自定义 Bundle ID。

④ 取包：点进运行记录 → 底部 Artifacts → 下载 FaceShy-unsigned-ipa → 解压得 IPA。

首次推送会弹 GitHub 浏览器登录；若改为让输入账号密码， 密码处填 Personal Access Token（勾选 repo 权限）。

路线 B · 找一台 Mac 跑一条命令

Terminal
cd FaceShy
chmod +x build_ipa.sh
./build_ipa.sh                       # 产物 build/FaceShy-unsigned.ipa
BUNDLE_ID=com.你的名字.faceshy ./build_ipa.sh   # 换 Bundle ID

脚本流程：xcodebuild 以 CODE_SIGNING_ALLOWED=NO 编译 Release + arm64 → .app 放入 Payload/ → 打成符合 iOS 规范的未签名 IPA → 自动打印安装指引。

拿到 IPA 后：自签工具怎么选

工具运行位置说明
SideloadlyWindows / macOS 电脑最省事：选 IPA → 填 Apple ID → Start，自动签名并安装
AltStore / SideStoreiPhoneIPA 存到「文件」，App 内导入安装
轻松签 / ESign / 全能签iPhone导入 IPA，用免费证书签名后安装
爱思助手Windows需先自签再安装，不能直接装未签名包

免费 Apple ID 限制：签名 7 天有效期，到期重签；最多同时 3 个自签 App。有 99 美元开发者账号则 1 年。

安装后第一次打开会提示「不受信任的开发者」：到 设置 → 通用 → VPN与设备管理 → 开发者App → 选中你的 Apple ID → 信任。设备需 iOS 16.0+。

自签前建议先校验（跨平台，Windows 也能跑）

Terminal
python3 tools/pack_ipa.py --verify build/FaceShy-unsigned.ipa

检查 Payload/ 结构、Info.plist 关键字段、 二进制是否为 arm64（不是 arm64 真机装不上）、可执行权限位、签名状态。CI 里也跑了这一步。 已拿到 .app 想自己打包： python3 tools/pack_ipa.py /path/to/FaceShy.app
